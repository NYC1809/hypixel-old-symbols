# Hypixel Skyblock old symbols

Client-side Fabric mod for reverting Hypixel's newer custom symbol characters back to older ASCII-style replacements.

By restoring the classic ASCII-style stat symbols, this mod ensures that other mods receive the expected characters instead of Hypixel's newer custom symbols. This allows features like custom Health and Mana bars, along with other mods that parse stat symbols, to function as intended.
